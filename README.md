# Bilibili Popular Video API Crawler (B站热门视频爬虫)

## 📖 项目简介
本项目是一个基于 Python 的纯协议网页爬虫实战项目。目标是抓取 Bilibili（B站）热门视频列表的核心数据（标题、UP主、视频链接），并持久化保存为 Excel 表格。

在开发过程中，通过浏览器抓包与前端 JS 逆向，成功突破了 B 站接口的 `w_rid` 动态签名校验机制，实现了完全脱离浏览器环境的自动化数据采集。

## ✨ 核心功能与特性

*   **突破接口签名防爬**：逆向分析了 B 站 API 的 `w_rid` 加密逻辑，成功还原了“时间戳 + 业务参数 + 固定盐值”的 MD5 签名算法，并实现了纯 Python 动态生成。
*   **高仿真请求伪装**：配置了完整的 Headers（包含 `用户代理`, `Referer`, `中-中-阿` 等指纹信息）以及 Cookie，有效降低了被服务器风控拦截的概率。
*   **健壮的 JSON 解析**：使用 `.get（）` 链式取值方法，优雅处理嵌套字典结构，避免了因个别视频字段缺失（如无封面、无UP主）导致的程序报错崩溃。
*   **便捷的数据落地**：使用 `熊猫` 对提取的字典数据进行结构化处理，一键导出为排版工整的 `.xlsx` 表格文件。
